                    快速开始: DMA方案 (30分钟)
================================================================================

【第1步】CubeMX配置 (10分钟)
─────────────────────────────────────────────────────────────────────────────
1. 打开你的 .ioc 文件
2. Connectivity → SPI6 → DMA Settings → Add
3. 选择: SPI6 TX
4. 设置:
   - Mode: Normal
   - Priority: High
   - Data Width: Byte to Byte
5. System Core → NVIC → Enable DMA2_Stream5 interrupt
6. Project → Generate Code

【第2步】替换代码 (2分钟)
─────────────────────────────────────────────────────────────────────────────
在BSP目录:
  cp bsp_led.c bsp_led.c.backup
  cp bsp_led_dma.c bsp_led.c

【第3步】处理D-Cache (仅STM32H7) (5分钟)
─────────────────────────────────────────────────────────────────────────────
打开 bsp_led.c，查看第90-110行:

如果看到这样的错误编译:
  "section '.dtcm_ram' not found"

改为:
  __attribute__((section(".ram_d3")))

【第4步】编译 (3分钟)
─────────────────────────────────────────────────────────────────────────────
make clean
make -j8

预期结果: 编译成功，无错误

【第5步】测试 (10分钟)
─────────────────────────────────────────────────────────────────────────────
烧录后运行:
  BSP_LED_Init();
  BSP_LED_SetMode(LED_MODE_BREATHE, 0, 40, 255);
  for (;;) {
    BSP_LED_Task();
    osDelay(20);
  }

观察30秒: 应该看不到闪白光 ✓

【常见问题】
─────────────────────────────────────────────────────────────────────────────
Q: 编译错误 'hdma_spi6_tx' 未定义
A: CubeMX没生成DMA，重新配置第1步

Q: 警告 '.dtcm_ram' section not found
A: 改用 '.ram_d3'（见第3步）

Q: 仍有闪白光
A: 检查:
   1. DMA中断是否启用 (NVIC)
   2. 用示波器测PA7波形
   3. 查看 DMA_SOLUTION.md

【关键检查点】
─────────────────────────────────────────────────────────────────────────────
□ CubeMX生成了 hdma_spi6_tx 
□ stm32h7xx_it.c 有 DMA2_Stream5_IRQHandler
□ bsp_led_dma.c 编译无错
□ LED任务优先级 ≤ 其他关键任务
□ 运行30秒无闪白光
