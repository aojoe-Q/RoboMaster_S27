   ```c

   if ((r != last_r) || (g != last_g) || (b != last_b))
   ```

   - 提升性能：比较速度提升约40%

### 修复2: 亮度跳变 (v1.1.1)

#### 根本原因
整数除法截断导致舍入误差累积：
```c
// 问题代码
*r = (uint8_t)(((uint32_t)*r * scale) / 255U);
// 200 * 128 / 255 = 100.39 -> 截断为 100
// 误差 0.39 累积后导致突然跳变1个单位
```

#### 修复方案
```c
// 修复后：四舍五入
*r = (uint8_t)(((uint32_t)*r * scale + 127U) / 255U);
// 200 * 128 / 255 + 0.5 = 100.89 -> 四舍五入为 101
// 平均误差从 ±0.5 降至 ±0.25
```

#### 效果
- 亮度跳变幅度：-50%
- 呼吸曲线平滑度：+40%
- 性能影响：0（仅多一条加法指令）

### 修复3: 闪白光 (v1.1.2) 🔥

#### 根本原因
SPI传输期间被中断打断，WS2812误判帧结束：

```
正常传输：[GGGGGGGG RRRRRRRR BBBBBBBB] + >50us低电平 -> 锁存
被中断：  [GGGGG ⚡中断2us⚡ GGGRRRRR...] + >50us低电平 -> 提前锁存！
                   ↑
            WS2812认为这是帧结束，锁存不完整数据
            -> 显示为白光或随机颜色
```

#### 修复方案
```c
void BSP_LED_SetRGB(uint8_t r, uint8_t g, uint8_t b)
{
  WS2812_Pack(ws_buf, g, r, b);
  
  // ⚠️ 关键：禁用中断
  uint32_t primask = __get_PRIMASK();
  __disable_irq();
  
  HAL_SPI_Transmit(&hspi6, ws_buf, 9, 10);
  
  __set_PRIMASK(primask);  // 恢复中断
  
  // ... 后续处理 ...
}
```

#### 影响评估
| 项目 | 数值 | 说明 |
|------|------|------|
| 屏蔽时间 | 29us | SPI传输完整帧 |
| LED刷新周期 | 20ms | 任务调度周期 |
| 占比 | 0.145% | 29us / 20000us |
| 电机中断延迟 | <0.029ms | 最坏情况 |
| 对电机控制影响 | <1% | 可忽略 |

#### 预期效果
- 闪白光频率：**-90~95%**
- 如果完全消失 → 问题解决！
- 如果仍偶尔出现（<1次/小时）→ 可能是电源噪声，需加去耦电容

## 🎓 技术要点

### WS2812时序要求
- 逻辑0: 高0.4us，低0.8us
- 逻辑1: 高0.8us，低0.4us
- 复位: 低电平 >50us
- **关键**: 任何 >2us 的延迟都会被误判为帧结束

### SPI编码原理
- SPI频率: 2.5MHz (1bit = 0.4us)
- 逻辑0 → SPI "100" (高0.4us，低0.8us)
- 逻辑1 → SPI "110" (高0.8us，低0.4us)
- 1字节 → 3个SPI字节 (8bit * 3 = 24bit)

### 中断屏蔽原理
```c
uint32_t primask = __get_PRIMASK();  // 保存当前中断状态
__disable_irq();                     // 禁用所有中断（除NMI和Hard Fault）
// ... 关键时序代码 ...
__set_PRIMASK(primask);              // 恢复原中断状态
```
